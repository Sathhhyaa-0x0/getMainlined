# getMainlined

> "The missing guide between wanting to contribute 
> to Linux kernel and actually doing it."

getMainlined is a navigation and orientation guide
for aspiring Linux kernel contributors.

Not another "how the kernel works" resource.
The first repo navigator built specifically
for people who want to get their first patch merged.

## What's inside

- Complete map of torvalds/linux folder structure
- Every subsystem explained in plain English
- Difficulty ratings for every area
- Contributor paths by subsystem
- Execution journeys across subsystems
- Your first patch guide

## Who this is for

Developers who opened torvalds/linux,
saw 70,000 files, and didn't know where to start.
